Clustering
==========

Notebook: `clustering.ipynb`
Dataset:
- `Wholesale customers data.csv`

Description
-----------
This notebook demonstrates clustering and segmentation workflows, including:
- Data preprocessing and scaling
- Choosing number of clusters (elbow, silhouette)
- Running clustering algorithms (KMeans, hierarchical)
- Interpreting cluster centers and segment profiles

How to run
----------
1. Install dependencies: `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`.
2. Open `clustering.ipynb` in VS Code, choose your kernel, restart kernel, then Run All.

Notes
-----
- Ensure `Wholesale customers data.csv` path is correct relative to the notebook. Update the path if needed.
- For reproducible results, set random seed where applicable.
