Association Rule Mining
=======================

Notebook: `association_rule_mining.ipynb`
Dataset:
- `Groceries_dataset.csv`
- Output: `association_rules_output.csv` (generated by notebook)

Description
-----------
This notebook uses PyCaret's association rule mining utilities to:
- Load transactional dataset (transaction id + item id)
- Setup association rule mining pipeline
- Generate frequent itemsets and association rules (Apriori-style)
- Visualize rules and save results

How to run
----------
1. Ensure the kernel includes `pandas` and `pycaret`.
   - For PyCaret 2: install `pycaret==2.3.5` (conda recommended on Windows).
2. Open `association_rule_mining.ipynb`, select the kernel, and `Run All`.

Notes
-----
- The notebook expects `Transaction` and `Item` columns. If your CSV has different column names, update the `setup()` call accordingly.
- If importing `pycaret.arules` fails, install PyCaret into the notebook kernel (this can be slow). Prefer pre-configured conda env.
