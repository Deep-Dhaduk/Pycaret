Regression
==========

Notebook: `regression.ipynb`
Dataset:
- `real_estate_dataset.csv`

Description
-----------
This notebook covers building regression models with PyCaret: data preparation, model comparison, evaluation, and saving the best model.

How to run
----------
1. Ensure `pycaret`, `pandas`, and `numpy` are installed in your kernel.
2. Open `regression.ipynb`, select the kernel, restart if needed, and run cells from the top.

Notes
-----
- Update the `data = pd.read_csv(...)` path if your CSV is located elsewhere.
- If PyCaret import or package installation fails, consider using conda with Python 3.8 for PyCaret 2.
